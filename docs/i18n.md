# CI18nManager — MTEngineSDL Internationalization System

## Quick Start

```cpp
#include "CI18nManager.h"

// 1. Define a plural rule
static EI18nPluralCategory PluralCardinalEN(double n, int i, int v, int w, int f, int t) {
    if (i == 1 && v == 0) return I18N_PLURAL_ONE;
    return I18N_PLURAL_OTHER;
}

// 2. Register a locale
SI18nLocale en;
en.tag = "en";
en.displayName = "English";
en.cardinalRule = PluralCardinalEN;
en.ordinalRule = nullptr;
en.numberFormat.decimalSeparator = ".";
en.numberFormat.thousandsSeparator = ",";
en.numberFormat.groupingSize = 3;
CI18nManager::Instance()->RegisterLocale(en);

// 3. Load string table
CI18nManager::Instance()->LoadStrings("en", "assets/locale/en.json");

// 4. Set active locale
CI18nManager::Instance()->SetActiveLocale("en");

// 5. Display translated text
ImGui::Text("%s", _T("menu.file.save"));  // "Save"
```

## API Reference

### Singleton

```cpp
static CI18nManager *CI18nManager::Instance();
```

Returns the global singleton instance. Created on first call.

### Locale Management

```cpp
void RegisterLocale(const SI18nLocale &locale);
```
Registers a locale with its BCP-47 tag, display name, plural rules, and number format. The tag is normalized on registration (see BCP-47 section). Rebuilds fallback chains for all registered locales.

```cpp
void SetActiveLocale(const string &tag);
```
Sets the active locale. All subsequent calls to `Get()`, `Format()`, `FormatNumber()`, and `GetPluralCategory()` without an explicit locale tag will use this locale.

```cpp
const string &GetActiveLocale() const;
```
Returns the current active locale tag.

```cpp
const SI18nLocale *GetLocale(const string &tag) const;
```
Returns the locale definition for the given tag, or `NULL` if not registered.

```cpp
const vector<SI18nLocale> &GetRegisteredLocales() const;
```
Returns all registered locales in registration order.

### String Tables

```cpp
bool LoadStrings(const string &localeTag, const string &jsonPath);
```
Loads strings from a JSON file into the string table for the given locale. Returns `false` on file read/parse error. Invalidates the miss cache for this locale and all locales that depend on it via fallback chains.

JSON format:
```json
{
    "meta": { "locale": "en", "version": 1 },
    "strings": {
        "key": "value",
        "other.key": "other value"
    }
}
```

```cpp
void SetString(const string &localeTag, const string &key, const string &value);
```
Sets a single string in the table. Same miss cache invalidation as `LoadStrings()`.

### String Lookup

```cpp
const char *Get(const string &key) const;
const char *Get(const string &key, const string &localeTag) const;
```

Looks up a string by key, following the fallback chain if not found in the requested locale. The first overload uses the active locale.

**Return value**: Pointer to internally-stored string. Valid until next `LoadStrings()` call for that locale. Never returns `NULL`.

**Fallback behavior**:
1. Try the requested locale
2. Walk the fallback chain (tag truncation + explicit fallbacks)
3. If all fail: intern the key itself and return a pointer to it, logging a warning on first miss

**Miss caching**: Once a key is confirmed missing across the entire fallback chain for a locale, the miss is cached. Subsequent lookups for the same (locale, key) pair skip the chain walk. Cache is invalidated when strings are loaded/set.

### Plural Resolution

```cpp
EI18nPluralCategory GetPluralCategory(double n) const;
EI18nPluralCategory GetPluralCategory(double n, const string &localeTag) const;
```

Returns the CLDR plural category for a number using the active (or specified) locale's cardinal rule. If no rule is registered, returns `I18N_PLURAL_OTHER`.

```cpp
static const char *PluralCategoryName(EI18nPluralCategory cat);
```

Returns the string name: `"zero"`, `"one"`, `"two"`, `"few"`, `"many"`, or `"other"`.

### ICU-like MessageFormat

```cpp
string Format(const string &pattern, const map<string, SI18nArg> &args) const;
string Format(const string &pattern, const map<string, SI18nArg> &args,
              const string &localeTag) const;
```

Formats a pattern string with the given arguments. The first overload uses the active locale.

**Pattern caching**: Patterns are compiled to a locale-independent AST on first use and cached. Subsequent calls with the same pattern string skip parsing. The cache holds up to 4096 entries; on overflow it is cleared entirely.

**Error handling**: Malformed patterns return the raw pattern text + `LOGWarning()`. Never crashes.

See "MessageFormat Syntax" section below for full syntax reference.

### Number Formatting

```cpp
string FormatNumber(double n) const;
string FormatNumber(int n) const;
string FormatNumber(double n, const string &localeTag) const;
string FormatNumber(int n, const string &localeTag) const;
```

Formats a number using the locale's configured separators and grouping. Integer overloads produce no decimal point. Double overloads show up to 6 significant decimal digits.

Examples:
- English: `FormatNumber(1234567)` -> `"1,234,567"`
- Polish: `FormatNumber(1234567)` -> `"1 234 567"`
- Italian: `FormatNumber(1234.5)` -> `"1.234,5"`

## MessageFormat Syntax

### Simple Substitution

```
Hello, {name}!
```

Replaces `{name}` with the string representation of the argument. Numbers are locale-formatted.

### Plural

```
{count, plural, one {# item} other {# items}}
```

Selects a branch based on the CLDR plural category of the numeric argument. `#` inside a plural branch is replaced with the locale-formatted number.

**All 6 categories**: `zero`, `one`, `two`, `few`, `many`, `other`. Use only the categories your language needs; `other` is required as the fallback.

**Exact match**: `=0`, `=1`, `=2`, etc. take precedence over category matching:
```
{count, plural, =0 {none} =1 {exactly one} other {# items}}
```

**Offset**: Subtracts from the number before category evaluation and `#` display:
```
{count, plural, offset:1 =0 {nobody} =1 {just you} other {you and # others}}
```

### Select

```
{gender, select, masculine {He} feminine {She} other {They}}
```

Matches the string value of the argument against branch keys. Requires an `other` branch as fallback. This is the universal mechanism for any string-keyed feature (gender, article class, politeness level, classifier, etc.).

### Selectordinal

```
{n, selectordinal, one {#st} two {#nd} few {#rd} other {#th}}
```

Like `plural`, but uses the locale's ordinal rule instead of cardinal rule.

### Nesting

All types can be nested recursively:
```
{gender, select, masculine {{count, plural, one {He found # item} other {He found # items}}} feminine {{count, plural, one {She found # item} other {She found # items}}} other {{count, plural, one {They found # item} other {They found # items}}}}
```

### Escaping

| Syntax | Result | Notes |
|--------|--------|-------|
| `''` | literal `'` | Consumed immediately |
| `'...'` | literal text | Everything inside is literal, no parsing |
| `{{` | literal `{` | Outside quoted sections only |
| `}}` | literal `}` | Outside quoted sections only |
| `{...}` | placeholder | Parsed recursively |

Edge cases:
- Unmatched `'` at end of string: treated as literal apostrophe
- Unmatched `{` without `}`: parse error -> raw text fallback + warning
- Unmatched `}` outside any block: treated as literal `}`
- `{{` inside `'...'` quotes: literal `{{` (quotes win)

### Not Supported

These ICU features are not implemented:
- `{n, number}`, `{d, date}`, `{t, time}` argument types
- `choice` format
- Full CLDR numbering systems (Arabic-Indic digits, etc.)

## CLDR Plural Rules

### Writing a Plural Rule

A plural rule is a function with this signature:

```cpp
EI18nPluralCategory MyRule(double n, int i, int v, int w, int f, int t);
```

**Operands** (from the CLDR specification):

| Operand | Meaning | Example for "1.50" |
|---------|---------|-------------------|
| `n` | Absolute value of the number | 1.50 |
| `i` | Integer part of n | 1 |
| `v` | Visible fraction digits WITH trailing zeros | 2 |
| `w` | Visible fraction digits WITHOUT trailing zeros | 1 |
| `f` | Visible fraction as integer WITH trailing zeros | 50 |
| `t` | Visible fraction as integer WITHOUT trailing zeros | 5 |

Most languages only need `n` and `i`. The full set ensures any CLDR rule can be expressed.

### Categories

| Category | Typical usage |
|----------|--------------|
| `I18N_PLURAL_ZERO` | Arabic (0 items) |
| `I18N_PLURAL_ONE` | English (1 item), Polish (1) |
| `I18N_PLURAL_TWO` | Arabic (2 items), Welsh |
| `I18N_PLURAL_FEW` | Polish (2-4), Czech (2-4) |
| `I18N_PLURAL_MANY` | Polish (5-21), Arabic (3-10) |
| `I18N_PLURAL_OTHER` | Default fallback (always required) |

### Example: Polish Cardinal Rule

```cpp
static EI18nPluralCategory PluralCardinalPL(double n, int i, int v, int w, int f, int t)
{
    if (i == 1 && v == 0) return I18N_PLURAL_ONE;

    int mod10 = i % 10;
    int mod100 = i % 100;

    if (v != 0) return I18N_PLURAL_OTHER;
    if (mod10 >= 2 && mod10 <= 4 && (mod100 < 12 || mod100 > 14)) return I18N_PLURAL_FEW;
    if ((mod10 == 0 || mod10 == 1) || (mod10 >= 5 && mod10 <= 9) || (mod100 >= 12 && mod100 <= 14))
        return I18N_PLURAL_MANY;
    return I18N_PLURAL_OTHER;
}
```

## Typed Arguments (SI18nArg)

```cpp
SI18nArg(int v);                           // Integer: v=0
SI18nArg(double v, int fracDigits = -1);   // Double: explicit fracDigits or unknown
static SI18nArg FromDecimal(const char *s); // From string "1.50" — exact operands
SI18nArg(const string &v);                 // String
SI18nArg(const char *v);                   // String (C-string)
```

For plural rules, use the type that matches your data:
- **Integer counts**: `SI18nArg(5)` — v=0, correct for most languages
- **Currency/decimal**: `SI18nArg::FromDecimal("1.50")` — preserves trailing zeros for v/w/f/t operands
- **String switches**: `SI18nArg("masculine")` — for `select` branches

## BCP-47 Locale Tags

Accepted format: `language[-script][-region]` where:
- `language`: 2-3 lowercase letters
- `script`: 4 titlecase letters (optional)
- `region`: 2 uppercase letters or 3 digits (optional)

On `RegisterLocale()`, the tag is normalized:
- `"ZH-hans-cn"` -> `"zh-Hans-CN"`
- `"en"` -> `"en"` (no change)

### Fallback Chain Construction

For a tag like `"zh-Hans-CN"`:
1. Start with the tag itself: `["zh-Hans-CN"]`
2. Truncate segments: `["zh-Hans-CN", "zh-Hans", "zh"]`
3. Append explicit fallbacks (e.g. `["en"]`): `["zh-Hans-CN", "zh-Hans", "zh", "en"]`

Only tags that have registered locales are kept in the final chain.

## Locale-Aware Number Formatting

Configure per locale via `SI18nNumberFormat`:

```cpp
struct SI18nNumberFormat {
    string decimalSeparator   = ".";   // "." or ","
    string thousandsSeparator = ",";   // "," or "." or " "
    int groupingSize          = 3;
};
```

Applied by `FormatNumber()` and by `#` inside `plural`/`selectordinal` branches.

## String Table JSON Format

```json
{
    "meta": { "locale": "en", "version": 1 },
    "strings": {
        "menu.file": "File",
        "menu.file.save": "Save",
        "game.items_count": "{count, plural, one {# item} other {# items}}"
    }
}
```

**Key naming convention**: Use dot-separated hierarchical keys (e.g. `menu.file.save`, `editor.attack`, `table.name`).

The `meta` object is optional but recommended. The `strings` object is required.

## _T() and _TID() Macros

### _T(key) — Simple Lookup

```cpp
#define _T(key) CI18nManager::Instance()->Get(key)
```

Use for stateless ImGui widgets and general text display:
```cpp
ImGui::Text("%s", _T("game.score_label"));
ImGui::Button(_T("btn.add"));
ImGui::MenuItem(_T("menu.file.save"), shortcut);
```

### _TID(key, imguiId) — Stable ImGui ID

```cpp
const char *_TID(const char *key, const char *imguiId);
```

Returns `"Translated Label##imguiId"` in a thread-local buffer. Use for stateful ImGui widgets that track internal state by ID:

```cpp
ImGui::InputText(_TID("editor.name", "name"), buf, sizeof(buf));
ImGui::InputInt(_TID("editor.attack", "attack"), &attack);
ImGui::CollapsingHeader(_TID("section.stats", "stats"));
```

Without `_TID()`, changing the active locale would change the ImGui ID, causing widgets to lose state (input focus, scroll position, tree expansion, etc.).

**Stateless widgets** (`Text`, `Button`, `MenuItem`, `Separator`) can use plain `_T()`.
**Stateful widgets** (`InputText`, `InputInt`, `TreeNode`, `CollapsingHeader`, `Combo`, `Checkbox`, `Slider*`, `Drag*`, `BeginTable`, `BeginTabItem`) must use `_TID()`.

## Thread Safety

- **String table loading**: Should be done before rendering starts (during initialization). Not thread-safe with concurrent `Get()` calls.
- **Locale switching**: Call `SetActiveLocale()` on the main thread only.
- **Get() and Format()**: Safe to call from the main/render thread. The pattern cache and miss cache use `mutable` members — safe for single-threaded rendering but not for concurrent access from multiple threads.
- **_TID()**: Uses a thread-local buffer — safe from any thread, but the returned pointer is only valid until the next `_TID()` call on the same thread.

## Adding a New Language

1. Write a plural rule function following the CLDR specification for the language
2. Create `SI18nLocale` with BCP-47 tag, display name, plural rules, and number format
3. Call `RegisterLocale()`
4. Create a string table JSON file with translations
5. Call `LoadStrings()` to load the file
6. Call `SetActiveLocale()` to switch to the new language
